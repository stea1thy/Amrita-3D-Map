# Visual QA Reference Photos (`pipeline/refs/`)

Store reference satellite screenshots and real-world photos here so the `campus-visual-qa` Visual Critic subagent can compare rendered 3D outputs side-by-side.

## Naming Convention
- `<target>_sat.jpg` (or `.png`) — top-down satellite reference (for example: `ab1_sat.jpg`, `ab3_sat.jpg`, `workshops_sat.jpg`)
- `<target>_irl.jpg` (or `.png`) — real-world aerial or eye-level architectural photo (for example: `ab1_irl.jpg`, `ab3_irl.jpg`)

Matching verification renders generated by `pipeline/render_check.py` are written to `pipeline/renders/<target>_top.png` and `pipeline/renders/<target>_front.png` (git-ignored).
